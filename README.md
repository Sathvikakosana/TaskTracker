# TaskTracker

A small task manager built with vanilla HTML, CSS, and JavaScript. No framework, package manager, or build step is required.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in Chrome, Firefox, Safari, or Edge.
3. Add a task and try the filters, completion checkbox, and clear button.


## Features
- Add and delete tasks
- Mark tasks as complete
- Filter tasks
- Persist tasks in browser local storage
- Responsive dark interface


## Bug-fix challenge
This repository intentionally contains **three bugs**. Try these test cases:
1. Create two tasks, complete one, then reload the page.
2. Create one completed task and one active task, then use the **Done** filter.
3. Create one completed task and one active task, then use **Clear completed**.

Find the root cause of each issue, fix it, and test again. The README intentionally does not include the solutions.

- `index.html` — page structure
